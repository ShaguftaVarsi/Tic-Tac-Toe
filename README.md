A lightweight, mobile-friendly Tic-Tac-Toe built with **HTML, CSS and vanilla JavaScript**.  
When a player wins you’ll see a real confetti celebration 🥳 and hear a short victory sound.  
The game resets instantly with a “Play Again” button or the in-game “Restart Game” control.

<br/>

## ✨ Features
- **Responsive layout** — scales down to ~320 px wide screens
- **Confetti celebration** on victory, powered by _canvas-confetti_
- **Sound effect** on wins (tiny MP3, replaceable)
- **Full-screen result screen** showing Win / Draw + “Play Again”
- Zero dependencies for gameplay logic (just one CDN for confetti)
